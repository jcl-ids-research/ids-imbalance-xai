# RM-DMVT 项目手册

**包名**：`ids-diffusion` 0.1.0 · Python ≥ 3.10 · MIT
**对应论文**：*Diagnosing Discrete-Marginal Collapse in Diffusion-Augmented Intrusion Detection: Rank-Matched Correction and Applicability Boundaries*

---

## 0. 这个项目是什么

一句话：**用类别条件扩散给不平衡入侵检测数据做增强，诊断出离散属性在连续扩散下会坍缩，用秩匹配校正修好它，并测出这套增强在什么条件下有效、什么条件下无效甚至有害。**

本仓库同时承担三件事：

1. **可运行的实现**——四个公开基准上的完整实验流水线；
2. **可复核的证据**——论文里每个数字对应的服务器归档结果；
3. **可追溯的出处**——生成论文数字的原始服务器代码快照，带逐文件哈希。

适用对象：

| 你是谁 | 从哪里开始 |
|---|---|
| 编辑 / 审稿人，想快速核对论文数字 | 第 1 节，2 秒到 3 分钟 |
| 审稿人，想完整重跑实验 | 第 5 节，需要 GPU 与公开数据集 |
| 接手的开发者 | 第 2、3、7 节 |
| 想确认代码没有被改写 | 第 6 节 |

## 1. 五分钟上手

### 1.1 安装

```powershell
uv sync --python 3.10 --all-groups
```

没有 `uv` 时先 `python -m pip install uv`。

> Windows 且路径含中文时，Python 3.10 的可编辑安装会丢弃 `.pth` 路径。改用 wheel 安装：
> ```powershell
> uv sync --python 3.10 --all-groups --no-editable
> uv run --no-sync ids-reproduce plan
> ```

### 1.2 不需要 GPU、不需要数据集的验证

这是核对论文最快的路径。仓库内已包含服务器归档结果，下面两条命令直接从归档重算论文里的每一个数字：

```powershell
uv run pytest tests/test_paper_claims.py
uv run ids-reproduce claims
```

输出形如：

```text
OK  unsw binary full model          paper=   88.90 archive= 88.9022 diff=+0.0022
OK  unsw fgsm drop, augmented       paper=   13.10 archive= 13.0986 diff=-0.0014
OK  largest balancing gain          paper=   17.70 archive= 17.6958 diff=-0.0042
claims=16 drifted=0
```

`drifted=0` 表示论文与归档证据完全一致。任何一项对不上都会以非零退出码失败。

### 1.3 完整测试

```powershell
uv run pytest          # 44 项，约 20 秒，默认跳过慢测试
uv run pytest -m slow  # 7 项端到端流水线，约 2 分钟
```

全部使用合成数据或仓库内归档结果，不需要外部数据，也不需要 GPU。

`-m slow` 那组会用微型合成数据集真实驱动 `ids-reproduce`，覆盖论文报告的全部六种「数据集 × 任务」组合：
四个基准的二元检测，以及有攻击类别标注的两个基准的多类任务。

## 3. 核心概念

### 3.1 流水线

```text
官方训练集
  ├─ 从训练集内部划出验证集
  ├─ 分位变换 + 类别条件 DDPM（只用训练行拟合）
  ├─ 逆分位变换回原空间
  ├─ 离散边际秩匹配校正        ← 本文的诊断与修复点
  └─ 受 15 倍上限约束的平衡训练集
            ↓
     多视图 Transformer 分类器
            ↓
     未经改动的真实测试集（只在最后评估一次）
```

### 3.2 四个消融变体

每次运行同时产出四个结果，用于分离组件贡献：

| 变体 | 扩散增强 | 多视图 |
|---|---|---|
| `full_model` | 有 | 有 |
| `wo_diffusion` | 无 | 有 |
| `wo_multiview` | 有 | 无 |
| `baseline` | 无 | 无 |

### 3.3 秩匹配校正（论文主张的核心）

连续扩散会把稀疏离散列压成密集近似值。校正的做法是：取生成样本在该列上的**秩**，用**真实训练数据的经验分位函数**回填。

因此必须诚实表述：**校正后离散边际的保真来自真实数据的分位迁移，不是扩散模型生成能力的功劳**。扩散仍然负责连续结构与秩序，但离散取值在校正后被绕过。

### 3.4 数据边界（不可违反）

- UNSW-NB15、NSL-KDD 使用**官方划分**，绝不合并、绝不重采样；
- CIC 两套没有官方划分，按种子做一次分层切分；
- 所有编码器、填充中位数、标准化、分位变换、DDPM、校正、平衡**只在训练分区拟合**；
- 验证集从训练集里切，绝不从测试集切；
- 测试集只在参数锁定后评估一次。

## 4. 命令手册

安装后有 9 个入口，全部 `--help` 可用。

### 4.1 复现主入口 `ids-reproduce`

| 子命令 | 作用 |
|---|---|
| `plan` | 列出论文表格背后的 18 次运行 |
| `check` | 训练前校验数据集文件，缺文件即非零退出 |
| `run` | 执行任务，可续跑（已有结果自动跳过） |
| `verify` | 把新跑结果与服务器归档逐指标做差 |
| `claims` | 从归档重算论文全部数字（无需 GPU） |

### 4.2 分步入口

| 命令 | 作用 |
|---|---|
| `ids-prepare` | 生成某数据集某种子的校正平衡缓存（支持四数据集、二元/多类） |
| `ids-train` | 从缓存训练四个消融变体并写指标 |
| `ids-eval` | 打印四变体指标表 |
| `ids-tune` | Optuna 分类器 / 扩散模块搜索（只看验证集） |
| `ids-confirm` | 候选参数三种子复核 |
| `ids-baseline` | 同划分同预处理下的对照模型 |
| `ids-freeze-split` | 冻结外层保留集划分并写清单 |
| `ids-prepare-holdout` | 生成保留集实验所需缓存 |

## 5. 完整复现流程

需要 GPU 与自行下载的公开数据集，来源与预期文件见 [DATASETS.md](DATASETS.md)。

```powershell
# 1. 看清要跑什么
uv run ids-reproduce plan

# 2. 训练前检查数据是否齐全
uv run ids-reproduce check `
  --data-root unsw=D:\data\UNSW-NB15 `
  --data-root nslkdd=D:\data\NSL-KDD `
  --data-root cicids2017=D:\data\CIC-IDS-2017 `
  --data-root cicddos2019=D:\data\CIC-DDoS2019

# 3. 正式运行（可中断续跑）
uv run ids-reproduce run `
  --data-root unsw=D:\data\UNSW-NB15 `
  --data-root nslkdd=D:\data\NSL-KDD `
  --data-root cicids2017=D:\data\CIC-IDS-2017 `
  --data-root cicddos2019=D:\data\CIC-DDoS2019 `
  --output runs\reproduction --device cuda

# 4. 与归档结果逐指标比对
uv run ids-reproduce verify --metrics runs\reproduction\metrics
```

**先做接线检查**：加 `--smoke` 可在笔记本上几分钟跑通全流程，但缩短的调度**不产出论文数字**。

矩阵构成：四个基准 × 三个种子的二元检测，加上有攻击类别标注的两个基准 × 三个种子的多类，共 18 次运行。资源以 GPU 小时计，主要消耗在类别条件 DDPM 训练。

## 6. 证据与出处

### 6.1 `evidence/paper_results/`

服务器权威结果中可公开的部分：主实验、经典与深度基线、多类、对抗评估、注意力分析、保真度报告与图件。仅包含 JSON、简短日志与不超过 2 MiB 的图；权重、预测数组、合成样本、缓存与数据库仍留在服务器。

### 6.2 `server_archive/legacy_paper/`

生成论文数字的**原始服务器代码不可变快照**，含 `SERVER_CODE_MANIFEST.json`（逐文件 SHA-256 与服务器环境）。

请勿修改该目录。维护中的实现放在 `src/ids_diffusion/`，它按同一协议重跑；快照的作用是让审阅者确认历史算法没有被悄悄改写。

## 7. 质量门禁与开发规范

```powershell
uv run ruff check src tests scripts
uv run ruff format --check src tests scripts
uv run pytest
uv run pytest -m slow
```

CI（`.github/workflows/ci.yml`）额外执行端到端流水线测试、`ids-reproduce claims` 与 `plan`。

工程约定：

- 边界处解析成类型化对象，领域内不再重复校验；
- 类型化错误（`ConfigurationError` / `DataShapeError` / `DatasetFileError` / `ViewPartitionError`），不用裸字符串异常；
- 不使用类型抑制注释，不删除失败测试；
- 严格 `basedpyright` 配置保留为**类型债务审计**，当前不是通过门禁，问题记录而非屏蔽；
- `legacy/` 两个子目录不纳入门禁，仅作出处保留。

## 9. 明确不主张的内容

- **不主张**在精度上全面超越经典基线。四个二元数据集中仅 NSL-KDD 领先，多类两项均落后；
- **不主张**统计显著性。仅 3 个种子，均值与标准差只描述波动，方向一致性是启发式判断；
- **不主张**在线、流式、抗漂移或生产就绪能力。全部评估建立在静态公开基准的固定划分上；
- **不建议**在以抗规避鲁棒性优先的场景启用该增强，除非另配防御手段。

## 10. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `ModuleNotFoundError: ids_diffusion`，但测试能过 | 中文路径下 Python 3.10 可编辑安装失效。用 `--no-editable` 重装，见 1.1 |
| `ids-reproduce check` 报缺文件 | 数据集目录不符合预期结构，对照 DATASETS.md 的文件清单 |
| CIC 数据集找不到 CSV | 传入发行根目录或直接传 `MachineLearningCVE` / `all` 子目录皆可 |
| 多类任务报错 | 多类仅对 UNSW-NB15 与 NSL-KDD 有效，CIC 两套没有攻击类别列 |
| `verify` 提示 REVIEW | 新跑结果与归档差异超出容差，检查设备、数据版本与种子；n=3 下小幅差异属预期 |
| 重跑很慢 | 主要成本是类别条件 DDPM；先用 `--smoke` 验证接线再投入 GPU 时间 |
