## 1. 工程组织决策

用户要求将后续所有活动代码集中到：

```text
D:\论文\code
```

PyCharm 直接打开该目录。论文、译文与编辑材料保留在 `D:\论文`，不再把活动代码散放在论文根目录。

统一工程采用一个 pipeline，而不是两个互不相关的项目：

```text
类别条件扩散生成
        ↓
秩匹配校正
        ↓
平衡后的训练数据
        ↓
多视图 Transformer 分类
        ↓
入侵检测结果
```

底层模块保持可拆分，以便分别调优和运行四种消融：

1. 完整 RM-DMVT；
2. 去掉扩散；
3. 去掉多视图；
4. 两个组件都去掉。

DDPM 与 Transformer 本身不是本文原创算法。本文可主张的是：统一的入侵检测流程、离散属性失效发现、秩匹配校正、组件分离测量与适用边界。

## 2. 为什么需要重新运行调优实验

调优不是更换有利样本，也不改变测试集，而是回答：

> 论文模型落后 XGBoost，究竟是模型结构本身不适合，还是固定参数没有充分发挥模型能力？

仍使用论文中的四个数据集与原有正确划分：

- UNSW-NB15；
- NSL-KDD；
- CIC-IDS-2017；
- CIC-DDoS2019。

实验规则：

```text
训练集   训练模型
验证集   选择参数
测试集   最终参数确定后，只评估一次
```

调优期间禁止依据测试集分数选择参数，避免测试泄漏。

第一阶段固定以前按照正确协议生成并经过秩匹配校正的数据，只优化分类器。这样每次试验的样本完全一致，能够判断提升来自模型参数，而不是重新生成了不同数据。

第二阶段固定第一阶段选出的分类器，再优化扩散模块。

## 3. 调优范围

### 3.1 多视图 Transformer

- 隐藏维度：64 / 128 / 256；
- 注意力头数：4 / 8；
- 编码器层数：2–6；
- 前馈层宽度；
- dropout；
- 学习率；
- 权重衰减；
- batch size；
- 线性融合或跨视图注意力。

### 3.2 扩散生成模块

- 扩散步数；
- 去噪网络宽度；
- 扩散学习率；
- 训练轮数；
- 扩增上限；
- 是否启用离散属性秩匹配校正。

两部分不应一次性做无约束联合搜索。先分别收缩搜索空间，再验证组合，才能解释提升来自哪个组件。

---

## 4. 预计时间

直接使用完整数据、三个种子跑 50 组参数，预计 25–35 小时，不合理。

推荐分阶段：

| 阶段 | 设置 | 预计时间 |
|---|---|---:|
| 快速筛选 | 单种子、约 30 个 trial、早停与剪枝 | 3–5 小时 |
| 候选复核 | 最优 3 组 × 三个种子 | 约 2 小时 |
| 扩散模块优化 | 约 15 个 trial | 3–4 小时 |
| 最终复跑 | 四数据集 × 三个种子 | 约 3 小时 |
| **合计** | | **约 8–14 小时** |

服务器 A100 可无人值守运行，所有结果写入独立目录，不覆盖论文原实验。

## 5. 调优目标

UNSW-NB15 当前结果：

```text
RM-DMVT    88.90 macro F1
XGBoost    90.20 macro F1
差距       -1.30
```

第一目标：公平调优后缩小 1.30 分差距。  
理想目标：达到或稳定超过 90.20。

同时必须满足：

1. 三个随机种子稳定；
2. 不以测试集选择参数；
3. NSL-KDD 现有 82.21 不明显退化；
4. 最终配置在四个数据集上重新复跑；
5. XGBoost 与本文模型的对比条件一致。

单次结果达到 90.20 不等于稳定领先。例如：

```text
RM-DMVT    90.25 ± 1.50
XGBoost    90.20 ± 0.31
```

波动远大于 0.05 分优势，不能声称稳定超过。

## 6. 达到或超过 90.20 后，论文价值如何变化

如果经过训练集/验证集上的规范调优，RM-DMVT 在 UNSW-NB15 上三个种子稳定达到或超过 90.20，并保持 NSL-KDD 领先，论文可增加一条可靠主张：

> 经过公平调优，扩散增强多视图模型不仅能够恢复稀有攻击线索，而且在仍有判别空间的表格式入侵数据上达到或超过最强经典基线。

此时论文贡献更完整：

1. 模型性能具有竞争力；
2. 发现并修正生成数据质量问题；
3. 给出组件贡献与适用范围。

如果系统调优后仍落后，也能证明差距主要来自深度模型与树模型在表格数据上的结构差异，而不是未认真调参。

## 7. 题目选择判据

当前题目：

> A Diffusion-Augmented Multi-View Transformer for Imbalanced Intrusion Detection: Rank-Matched Correction and Applicability Boundaries

若调优结果仍低于 XGBoost，保留当前“秩匹配校正与适用边界”定位。

若 UNSW-NB15 三个种子稳定超过 90.20、NSL-KDD 保持领先，并且其他数据集没有明显退化，可将架构重新放到题目中心，例如：

> An Optimized Diffusion-Augmented Multi-View Transformer for Imbalanced Intrusion Detection with Rank-Matched Discrete Correction

中文：

> 面向失衡入侵检测的优化扩散增强多视图 Transformer：秩匹配离散校正

只有在最终配置完成四数据集、三个种子复验后，才能决定是否使用架构主导题目。不能只挑调优后表现有利的数据集。
