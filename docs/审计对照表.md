# 审计对照表：论文 ↔ 证据 ↔ 代码

面向编辑与审稿人。本表回答一个问题：**论文里的每张表、每个关键数字，能不能在本仓库里找到对应的证据文件和生成代码？**

全部条目均由 `uv run ids-reproduce claims` 与 `uv run pytest tests/test_paper_claims.py`
自动校验，无需 GPU、无需下载数据集，耗时数秒。

---

## 1. 一条命令看结论

```powershell
uv run ids-reproduce claims
```

输出 33 项对照，`drifted=0` 表示论文与归档证据逐项一致。

## 3. 证据家族 → 生成代码

`server_archive/legacy_paper/` 是生成论文数字的原始服务器代码快照，带逐文件 SHA-256。

| 证据家族 | 主要生成脚本（位于快照内） |

| `phase1_corrected` | `deploy/scripts/correct_unsw_ablation.py`、`correct_cross_dataset.py` |
| `multiclass` | `deploy/multiclass_baselines.py`、`deploy/scripts/multiclass_data.py` |
| `baseline_fair` / `baseline_fair_multiclass` | `deploy/scripts/baseline_fair.py` |
| `baseline_deep` / `baseline_deep_multiclass` | `deploy/scripts/baseline_deep.py` |
| `adversarial` | `deploy/adversarial_*.py`、`deploy/scripts/adversarial_real.py` |
| `attention` | `deploy/scripts/attention_real.py`、`ablation/models/*` |
| `fidelity` | `deploy/check_discrete_collapse.py`、`fidelity_evaluation.py`、`plot_correction.py` |
| `figures` | `deploy/plot_*.py`、`server_redraw_figure*.py` |
| `scarcity` | `rm_dmvt/runs/minority/`（服务器产出，见下方说明） |

> **注意**：`baseline_fair_multiclass` 与 `baseline_deep_multiclass` 没有独立脚本。
> 二元与多类由同一份脚本产出，输出目录在运行时拼接：
> `root = out_root if task == "binary" else f"{out_root}_multiclass"`
> （见 `baseline_fair.py:201`、`baseline_deep.py:385`）。按目录名做字面搜索会误判为缺失。

## 4. 关键数字的独立校验

| 论文陈述 | 数值 | 归档重算 |
|---|---|---|
| UNSW 二元完整模型 | 88.90 ± 0.57 | 88.9022 / 0.5656 |
| UNSW 去扩散 | 87.22 ± 0.34 | 87.2166 / 0.3358 |
| NSL-KDD 二元完整模型 | 82.21 | 82.2062 |
| UNSW 多类 vs XGBoost | 45.93 / 49.52 | 45.9276 / 49.5196 |
| FGSM ε=0.05 掉点（增强 / 未增强） | 13.10 / 10.25 | 13.0986 / 10.2492 |
| CIC-DDoS2019 残留不平衡 | 1.07 : 1 | 1.0745 |
| 均衡收益（提升组数 / 总数 / 最大） | 15 / 16 / +17.70 | 15 / 16 / 17.6958 |
| 校正代价 UNSW | 0.12 ~ 0.93 | 0.1161 ~ 0.9292 |
| 校正代价 NSL-KDD | 1.92 ~ 2.69 | 1.9231 ~ 2.6923 |
| 预设容差 | 2.00 | 2.0000 |
| 稀缺性攻击类召回（增强 / 未增强） | 87.94 / 83.83 | 87.9364 / 83.8289 |
| 稀缺性提升 | +4.11 | 4.1075 |
| 稀缺性 XGBoost 攻击类召回 | 87.15 | 87.1518 |
| 稀缺性标准差（增强 / XGBoost） | 3.98 / 0.11 | 3.9787 / 0.1103 |
| 稀缺性多数类召回（增强 / 未增强） | 96.38 / 98.78 | 96.3847 / 98.7838 |
| 稀缺性 macro F1（增强 / XGBoost） | 91.71 / 92.11 | 91.7098 / 92.1117 |
| 稀缺性攻击行（稀释前 / 后） | 119,341 / 5,967 | 119341 / 5967 |

**关于 2.69**：该数字指**相关性保持度的损失**（`corr_within_0.10` 校正前后之差），
不是召回率。NSL-KDD seed 456 为 2.69 点，超出预先设定的 2 点容差，论文已如实披露。
校正后离散属性的 off-default 召回率恢复到约 100%（最低 99.98%，最高 101.60%）。

**关于稀缺性实验的逐种子分歧**：增强在 seed 42 与 123 分别带来 +6.57 与 +5.86 点召回，
但在 seed 456 为 **-0.11**，符号并不一致。论文据此明确表示不将其作为已确立的效应。
`tests/test_paper_claims.py::test_the_scarcity_gain_does_not_hold_at_every_seed`
把这一自我限制固化为可执行断言：若日后有人把该结论表述得更强，测试会失败。

## 5. 覆盖范围的诚实说明

**仓库内包含**：全部实现代码、四数据集加载与统一复现驱动、服务器原始实验代码快照、
权威结果的可公开部分（283 个文件）。

**仓库内不包含**：原始数据集（需按 [DATASETS.md](DATASETS.md) 自行从发布方下载）、
模型权重、预测数组、合成样本、Optuna 数据库。这些体积大且不影响结论核验，仍保存在训练服务器。

**保真度证据的种子覆盖不均**：UNSW 有 42/123/456 三个种子，其余三个数据集只有 123/456
两个种子。这是当时实验的实际情况，未做补齐，也未在论文中声称三种子完整覆盖。
